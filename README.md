# Three days in Zhangjiajie

Travel itinerary for 20–22 November 2026: the Zhangjiajie National Forest Park (Tianzi Mountain, Yuanjiajie, Wulong Village, Golden Whip Stream, Huangshizhai) and Tianmen Mountain Line C.

The whole site is one self-contained file, `index.html`. Fonts load from Google Fonts; photo links open the source sites.

## Publish with GitHub Pages

1. Create a new repository and upload `index.html`, `.nojekyll` and this README to the root of the main branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to “Deploy from a branch”, choose `main` and `/ (root)`, and save.
4. After a minute or two the site is live at `https://<your-username>.github.io/<repository-name>/`.

To print or save as PDF, use the browser’s print dialog: the print layout shows every branch.
